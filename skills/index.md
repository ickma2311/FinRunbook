Resolve this dictionary once per request and pin relative links to the same
repository commit. Read only selected methods. These first-party methods use
local Python; none dispatches another skill or requires MCP. Legacy specialist
entry points remain for compatibility, outside active routing and the bundle.

| Method | Description / when to use | Instruction |
| --- | --- | --- |
| company | Business drivers, competitive position, financial health and principal risks; substantial coverage needs statements and operating KPIs. | [Read](methods/company.md) |
| earnings | Compare actual results, prior guidance and new outlook with aligned fiscal periods; consensus requires a dated source. | [Read](methods/earnings.md) |
| statements | Analyze profitability, cash conversion, working capital, liquidity, leverage and accounting anomalies using comparable statements. | [Read](methods/statements.md) |
| valuation | Assess price-implied expectations, multiples or cash-flow value with explicit assumptions; disclose missing prices or estimates. | [Read](methods/valuation.md) |
| industry | Compare business models, sector KPIs, competitors and value flows while keeping incompatible scopes and denominators separate. | [Read](methods/industry.md) |
| datasheet | Extract and reconcile financial history across periods, units, restatements and sources; deliver CSV and requested XLSX. | [Read](methods/datasheet.md) |
| market | Prices, volume, returns, drawdown and benchmarks with timestamp and adjustment boundaries; Yahoo needs optional local yfinance. | [Read](methods/market.md) |
| radar | Discover and rank research topics using bounded public signals and primary events; deliver a shortlist or selected follow-up reports. | [Read](methods/radar.md) |

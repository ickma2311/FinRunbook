# Runs

Create one directory per research run. Generated runs are intentionally not
ignored: a team may review or version selected examples. Never commit secrets,
API keys, paywalled source bodies, or data whose terms prohibit redistribution.

Expected layout:

```text
runs/20260903-153012-datadog-vs-cloudflare/
  research-record.json
  report.md
  validation.json
  artifacts/
  sources/        # optional; only when local storage is permitted
```

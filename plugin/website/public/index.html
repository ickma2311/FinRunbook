A few practical questions.

Do I need a Finrun account?

No. The current skills-only edition runs through your agent. This website has no account or sign-in flow.

Does this run in web ChatGPT?

This edition is designed for Codex running locally with Python and file access. It is not supported in ChatGPT web. Open a local Codex workspace to use it.

Can Radar run every day?

Radar runs once when invoked. Recurring use needs an explicitly configured schedule in a supporting host. Installation does not enable background work.

Can I ask something outside these examples?

Yes. Change the companies, period, language, question and format. Coverage depends on available evidence and your agent’s tools.

What about usage and data costs?

Your agent’s usage limits and any data-provider charges still apply. The package does not supply subscriptions or credentials. This website does not collect payments.

Are the results investment advice?

No. Outputs support research and may contain errors or incomplete information. Review the original sources and get qualified advice for decisions that depend on your circumstances.

# Finrun support

Maintained by Chao Ma. These instructions cover the Finrun 0.5 preview plugin.

For a reproducible software problem, open a
[GitHub issue](https://github.com/ickma2311/FinRunbook/issues).
Include the plugin version, host agent, operating system, Python version,
redacted error message, and the smallest synthetic example that reproduces it.

GitHub Issues are public. Do not post API keys, passwords, identity documents,
account statements or private research records. Do not attach an entire
workspace or cache. Replace confidential values with synthetic examples.

For a privacy question or a report unsuitable for a public issue, email
[ickma2311@gmail.com](mailto:ickma2311@gmail.com). Send a minimal description
first; do not send credentials or identity documents. Email is handled through
the maintainer's Gmail account and the sender's provider. No response-time
commitment is offered for this preview.

For account, billing or authentication problems with your agent or a financial
data provider, contact that provider. Finrun installation does not grant paid
data access. See the [privacy notice](privacy-0.5.md) and
[terms of use](terms-0.5.md).

## Release scope

Version 0.5 provides one Finrun skill, including Radar topic discovery, local
helpers, a versioned public GitHub method catalog and validation. It requires a
compatible local agent, Python 3.10+, a writable workspace and source access.
It does not provide a brokerage, trading execution, managed portfolio, hosted
MCP endpoint or automatically enabled schedule. This plugin does not collect
payments. Availability in a public plugin directory depends on that host's
review and publication process.
